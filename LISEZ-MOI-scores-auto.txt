SCORES AUTOMATIQUES DEPUIS SPORTCORICO
=======================================

A EXTRAIRE DIRECTEMENT DANS  C:\Users\rapha\usap-app
Windows demandera de remplacer des fichiers : acceptez.
N'extrayez PAS dans un sous-dossier, sinon rien ne sera remplace.

Ensuite, dans PowerShell :

    cd C:\Users\rapha\usap-app
    npm run db:push
    npm run db:sportcorico
    npm run build
    git add .
    git commit -m "Scores automatiques depuis SportCorico"
    git push

Puis, dans l'application : Admin -> Scores auto -> "Tester sans enregistrer".
Verifiez que les scores lus sont justes, puis "Synchroniser maintenant".

SI UN SCORE EST FAUX
--------------------
Saisissez-le a la main dans Admin -> Matchs en laissant cochee la case
"Garder ce score" : la synchronisation ne le modifiera plus jamais.
