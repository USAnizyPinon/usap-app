CORRECTIF CARTE JEUNES — USAP

1. Aucun SQL nécessaire. Les participants éventuels sont lus côté serveur à l’affichage depuis SportCorico, sans publier le lien secret ICS.

2. Extraire le ZIP à la racine de C:\Users\rapha\usap-app en remplaçant les fichiers.
3. PowerShell :
cd C:\Users\rapha\usap-app
git add .
git commit -m "Cartes jeunes et calendrier SportCorico"
git push origin main

4. Dans Admin > Scores auto : Tester les jeunes sans enregistrer, puis importer.

IMPORTANT : Les listes de clubs ne peuvent être affichées que si le flux ICS les fournit explicitement dans une ligne « Clubs participants : ... », « Equipes participantes : ... » ou « Adversaires : ... ». La plupart des exemples transmis ne contiennent pas cette liste : un lien « Voir les participants dans SportCorico » apparaît si l'événement possède un lien exploitable.

Les 4 categories jeunes ont des horaires normalises à 10h Europe/Paris. Les scores des jeunes ne sont PAS synchronisés en direct : le flux ICS ne les fournit pas.
